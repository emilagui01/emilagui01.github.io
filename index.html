Hands-on projects

Practice projects I built myself to show I can do the everyday work of an IT support role.

Windows Server 2022 Active Directory Lab [COMPLETE] Managing employee accounts and work computers Completed

A virtualized Windows domain in Hyper-V: domain controller with DNS and DHCP, organizational units and security groups, a domain-joined Windows 11 client, Group Policy for drive mapping, restrictions, and Remote Desktop access, plus four resolved help desk tickets covering lockouts, password resets, disabled accounts, and policies not applying.

I built a small practice company network on my own computer using Active Directory, the Microsoft system most businesses use to manage employee logins and computers. I set up user accounts and teams, connected a work laptop to it, created settings that apply automatically (like shared drives and remote access), and solved four common help desk problems: locked-out accounts, password resets, disabled accounts, and settings that weren't taking effect.

Help Desk Ticketing System Deployment [COMPLETE] IT help desk request system Completed

osTicket on Ubuntu Server 24.04 (Apache, MariaDB, PHP), managed over SSH and connected to the Active Directory lab domain over LDAP with a least-privilege service account. SLA tiers, Tier 1 and Tier 2 departments, auto-routing help topics, role-based agent access, tickets worked through escalation, and a public and internal knowledge base.

I installed and set up a help desk system, the tool IT teams use to track every request employees send in. Employees sign in with their existing work login, requests are automatically sent to the right team, urgent issues get faster response deadlines, and harder problems are handed up to more experienced staff. I also wrote help articles so people can fix common issues on their own.

PowerShell Automation Lab [COMPLETE] Automating new-hire and departing-employee accounts Completed

Three PowerShell scripts that run the account lifecycle of the lab domain: bulk onboarding from CSV (department OUs, groups, private home folders), safe offboarding that disables and archives instead of deleting, and an HTML account health report. Every run supports -WhatIf, is logged, and is tied to an osTicket ticket number stamped on the account in AD.

I wrote small programs that handle repetitive account work automatically: setting up accounts for a group of new hires from a spreadsheet, safely shutting off accounts when people leave (saved and archived, never deleted), and producing a report on the health of all accounts. Every change can be previewed before it runs, is recorded, and is linked to the help desk request that asked for it.
